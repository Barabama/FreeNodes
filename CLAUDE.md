## Architecture Overview

AI-powered proxy node crawler replacing a Scrapy project. Scrapes blog sites for V2Ray/Clash subscription links using **rule-first + LLM fallback + self-healing** strategy.

### Data Flow

```
config.yaml (site definitions)
    ↓
Scheduler (asyncio.Semaphore concurrency control)
    ↓ parallel per-site
SiteProcessor (one per site, dispatched by site.type)
    ├─ simple: blog → article list → regex/LLM extract → download .txt/.yaml
    ├─ yt_pwd: blog → YouTube subtitle → password → decrypt → extract
    └─ cloud_drive: YouTube channel → Drive link → zip → extract
    ↓
Pipeline (dedup + save to nodes/{site}.txt|yaml)
    ↓
Merger (merged.txt + merged.yaml + provider.yaml)
    ↓
README update + config.yaml up_date persist
```

### LLM Routing (`src/llm_router.py`)

- **Weighted random** routing (not sequential) across providers: OpenRouter → Cerebras → Opencode
- **Health tracking**: 5 consecutive failures → provider disabled for 30 min, auto-recover
- **Task-aware**: `extract_links` and `generate_pattern` can have different provider weights (configurable in `config.yaml`)
- **Self-healing**: regex patterns generated by LLM are validated (syntax + recall + precision) before persisting to `config.yaml`
- Uses `AsyncOpenAI` (never sync `OpenAI` — blocks event loop)

### Site Type Dispatch (`src/site_processor.py`)

`SiteProcessor.run()` dispatches by `site.type` field:
- **simple**: blog listing → `_pick_articles()` → `_extract_links()` → download
- **yt_pwd**: blog → `_try_youtube_password_flow()` → YouTube subtitles → decrypt
- **cloud_drive**: `_run_cloud_drive()` → YouTube channel → Drive zip → extract

### Key Pattern: Rule-first + LLM + Self-heal

```
1. Check site.link_pattern (regex) → if matches, return (0 LLM tokens)
2. LLM extracts links from markdown
3. LLM generates a regex pattern from found links
4. Three-layer verification (syntax / recall / precision)
5. If passes → persist pattern to config.yaml (next run = 0 tokens)
```

## Project Structure

```
src/
  config.py          # SiteConfig, ProviderConfig, LLMConfig, CrawlConfig, Config
  crawler.py         # Page dataclass + fetch_page (Crawl4AI) + download_file (httpx)
  llm_router.py      # LLMRouter: weighted routing + health tracking + ask/extract/generate
  site_processor.py  # SiteProcessor: per-site lifecycle, dispatches by type
  scheduler.py       # Scheduler: asyncio gather with concurrency control
  merger.py          # Merger: cross-site dedup + provider.yaml with region groups
  pipeline.py        # process_txt (base64 decode + dedup) + save
  readme_updater.py  # Generate README.md subscription table from config + nodes/
  youtube.py         # yt-dlp wrapper: list_channel, get_metadata, subtitles, password extraction
  drive.py           # Google Drive download + zip extraction
  decryptor.py       # Playwright password input + brute-force (AABB/ABAB patterns)
  paste.py           # paste.to / PrivateBin client-side encrypted paste decryption
main.py              # CLI entry: python main.py [site_name]
config.yaml          # Site definitions + LLM routing + crawl strategy
tests/               # pytest-asyncio tests, ~175 tests total
```

## Testing Conventions

- Use `pytestmark = pytest.mark.asyncio` at top of test files with async tests
- Sync tests don't need the marker
- `monkeypatch` for mocking external calls (`src.llm_router.os.getenv`)
- `tmp_path` fixture for file I/O tests
- Test naming: `test_<function>_<scenario>` e.g. `test_extract_by_pattern_no_match`
- Each test file: `tests/test_<module>.py`
- **~175 tests, all must pass before commit**
